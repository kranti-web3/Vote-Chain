VoteChain
VoteChain is a secure, decentralized voting application built on the blockchain. It ensures complete privacy and transparency by utilizing advanced cryptographic techniques.
Features
 * Decentralized Voting: Powered by secure Solidity smart contracts.
 * Privacy-First: Uses Semaphore Protocol for anonymous, yet verifiable interactions through Zero-Knowledge Proofs.
 * Secure Backend: Integrated with Supabase for robust and efficient database management.
 * Time-Locked Transactions: Implements tlock-js for secure, time-locked data handling.
Technology Stack
 * Smart Contracts: Solidity
 * Backend: Supabase
 * Cryptography: Semaphore Protocol, Zero-Knowledge Proofs, tlock-js
